# Synthia Generative Address & Morphology Engine v0.1.0

This is the **full additive integration chassis**, not a one-off gate-pair demo. It is designed to grow as more source rules, graph families, dimensions, modalities, neural morphologies and hands are recovered.

## What is live now

- full addressed-node validation and canonical keys
- 36 Human Design channel-pair registry
- rule/evidence registry with established/source-supported/experimental states
- addressed connection compiler
- conditional graph instantiation and dissolution
- graph assemblies/pods by shared participation
- graph-energy competition by transparent active coverage/expression metrics
- deterministic morphology sockets with extension hooks
- multimodal projections (language, geometry, sound, color, timing) marked experimental where appropriate
- persistent graph-learning store that **cannot invent a connection**
- intact Cynthia r21.21 runtime bridge through her existing MCP bus and process fabric
- existing Hands package preserved untouched and loadable through an adapter
- local web/API dashboard
- donor archive/provenance manifest
- extension registry for future connection rules, morphologies, projections and processes

## Run

```bash
# after unzipping this package
cd Synthia-Generative-Address-Morphology-Engine-v0.1.0
npm test
npm run demo
npm start
```

Open `http://127.0.0.1:8787`. No npm install is required for the new engine itself.

## Cynthia

Cynthia is preserved, not rewritten. The bridge dynamically registers this engine as an additional MCP target/process at runtime. It does not modify her source files.

## Adding more later

Drop new source-supported rules/morphologies into the registries or add donor adapters. The chassis is deliberately registry-driven so future discoveries do not require another architecture reset.
