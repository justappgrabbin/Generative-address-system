# Donor roles

All donor archives are preserved untouched under `vendor/donors/`. They are sources of faculties, not replacements for Cynthia.

- **Generative-Morph-Chat**: ChannelResolver and emergent edge/function experiments; semantic/morph chat.
- **Generative-Process-Cluster**: channel/process composition, emergent junctions, process tiers.
- **neural-architecture-generator**: executable architecture-family generator/runtime.
- **Primitive-Neural-Network-Foundry**: primitive operators and network-genome construction.
- **Model-Weaver**: model/code mutation and training workbench lineage.
- **Neural-Network-Builder**: graph-neural/training/address calculation donor.
- **Mesh-Cognition-Network**: role automata, capability networks, grammars, shared cognition.
- **mesh-automaton**: deterministic mesh execution and Pure Synthia lineage.
- **meaning-mesh-64**: grounded intake, dependencies, evidence and unknowns.
- **synthia-mesh.mjs**: learned activation/weight dynamics. Preserved as donor; the live integration uses a stricter graph-only weight store that cannot create new connections.
- **SynthAI-Foundry-QQMOD-Replit-Drop**: factory/model contract, function sockets, manufacturing lifecycle.
- **Synthia-Coherent-Autonomy-Hands**: hands, heartbeat, safety, workspace, Android/Termux faculties and autonomy runtime.
- **Synthia-Top-3-Autonomy-Lineages-PARTIAL**: lineage/recovery plus the actual r21.21 chassis preserved separately under `vendor/cynthia-original/`.
- **alphabet-genealogy-lab**: symbolic transformation provenance.
- **address_space_engine.py**: deterministic address/state-space reference recovered from Library.

## Rule
A donor can contribute a capability through an adapter or registry. Donor assumptions never silently become canonical.
