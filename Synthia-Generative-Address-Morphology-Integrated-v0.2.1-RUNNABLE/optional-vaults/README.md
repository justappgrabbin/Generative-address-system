# Optional donor / lineage vaults

The runnable build excludes the bulky preserved donor ZIPs and the previous r21.21-based generated build only to keep distribution size manageable.

No live functionality depends on those archive files. Donor hashes and roles remain recorded in `provenance/DONOR_MANIFEST-v0.2.0.json`.

The full working source tree used to produce this distribution preserved those archives separately; they are lineage/reference material, not the active Synthia root.
