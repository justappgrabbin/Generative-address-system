# Synthia integrated morphing state space — integration branch

This is a **code integration**, not a replacement ontological state space and not a fifth factory. Preserved original archives remain untouched. The four primitive families are **Tool Factory, Neural Net Maker, Model Maker and Foundry**. Their lawful, executable contextual realization forms the swarm.

## Sources and boundaries

- Branch `codex/semantic-address-generation`: 69,120 symbolic gate/line/color/tone/base combinations at each recursive layer (lazy BigInt), source-backed structure views, contextual frame analysis, experimental lexical candidates and real Klein tool routing. Candidate lexical addresses with default or missing coordinates are NOT complete semantic authority.
- Branch `audit/ontological-integrity-20261021`: opt-in strict non-fabricating address validation, coordinate-based **experimental** projections and provenance tests. Keep numeric/angular conventions explicit; do not silently conflate validators.
- Branch `feature/klein-neural-symbolic-bridge-20261022`: 26-step limit, live Klein witness, explicit owner authorization, symbolic result references and receipts. Original Neural Net Maker and Foundry entrypoints must be supplied by actual callable adapters.
- Branch `add/euclid-klein-construction-20261022`: pure-JS generative frequency-layer reconstruction, visual grammar, Klein operations, Euclidean constructions and tests.
- Branch `add/moving-photo-20261021`: address-conditioned ModelMaker ImageField training, persistent chunk-backed model snapshots and photo warping. Experimental motion-to-meaning mappings do not constitute a finished morphing swarm.

## Shared runtime entry point

`src/swarm-morph-runtime.mjs` exports `createSwarmMorphingRuntime` and `auditOverlaySkin`. The existing `SynthiaGenerativeAssembly` has an additive `createSwarmRuntime(options)` method; `src/index-generative.mjs` exports the same adapter.

The runtime delegates structural interpretation to the **existing** Synthia assembly. A separate, complete 13-field canonical address is needed to execute. Klein evaluates the intended program and side effects require an owner policy. It does not mint coordinates from hashes or presume that a lexical prototype has resolved the complete address.

Registered capabilities include `image.store`, `image.reconstruct`, `image.observe`, `geometry.construct`, `skin.audit`, and owner-gated `model.train`. `neural.build` and `foundry.build` are only registered when supplied working factory callbacks. `skin.render` is only registered when a real renderer is provided.

`skin.audit` checks clipping, viewport geometry, 44px touch targets, text contrast and functional binding membership. It deliberately reports visual/transition review as unresolved. It cannot certify attractive UI design, photorealism, 3D asset quality or adaptive behavior without renderer evidence.

## Next build phases

1. Semantic cloud overlays: established/experimental semantic evidence exposed through the existing state-space, with no second source of address truth.
2. Spritesheet builder: preserve alpha, deterministic frames and timing; add frame/collision/hitbox/atlas integrity tests and animation preview.
3. Adaptive world/skin morphing: learned rules → constrained swarm plan → registered executable factory adapters → skin acceptance gate → observed outcome → learning.
4. Personalized initialization: with explicit consent, use birth date, precise time and place to compute traceable astronomical/configurational inputs. Any interpretive Human Design or astrology-based meaning must be labeled a project hypothesis, not a scientifically validated prediction of personality. Owner can edit or opt out and learning outcomes supersede defaults.
5. Bootable computer/game overlay: requires genuine Android/runtime packaging, storage permissions, app lifecycle, gesture handling and persistence tests. This branch alone is **not** a bootable APK.

## Verification

Run from the runnable directory:

`node --test tests/swarm-morph-runtime.test.mjs`

`npm run test:all`

For relevant extension suites, run `npm test` in `extensions/klein-neural-symbolic`, `extensions/generative-reconstruction`, `extensions/klein-visual-grammar`, `extensions/modelmaker-image-trainer`, and `extensions/moving-photo` when their package scripts exist. The dedicated smoke suite tests the actual existing image and geometry modules; factory callbacks are controlled stubs in unit tests, not false claims of end-to-end neural training.

No underlying original archives or donors were changed. This branch preserves main's existing 815 MB tracked history and does not claim to have shrunk it. Do not merge to main until CI, strict-address compatibility, and security findings are reviewed.
