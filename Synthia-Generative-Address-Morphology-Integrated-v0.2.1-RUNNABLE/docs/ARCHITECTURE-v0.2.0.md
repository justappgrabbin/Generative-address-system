## Graph lifecycle

A graph is instantiated only when a registered connection is valid under current rules. If the required addressed participants are no longer active or the connection no longer resolves, the graph becomes dissolved. Historical state may remain as provenance; inactive graphs are not treated as currently instantiated.

Graphs may form local assemblies when they share participating structures. Active graph energies are compared by the current transparent experimental ecology metric to expose a dominant energy. The metric is replaceable without changing Cynthia or the connection registry.

## Extension rule

New connection families, dimension laws, timing laws, geometry rules, awareness routing, neural morphology implementations and output substrates should be added through registries/adapters. Existing Synthia authority code does not need to be rewritten to add them.
