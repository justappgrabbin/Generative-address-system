# Synthia state-space foundation · first assembled build

Open **Synthia-Foundation-Offline.html** in a modern browser. It embeds the active modules and requires no download from a CDN. The source entry is `index.html`; `npm run serve` serves the files locally for browsers that restrict local-file modules. That server delivers static files; execution happens in the browser.

Chat and file upload share one live foundation. Chat enters reduction and admission, the supplied execution pipeline, Synthia learning, the Klein contact loop, the full Klein toolkit's Who/What/Where/When/Why analysis, ATO episodic storage, addressing, and mesh sharing. Select a tool in chat to execute its actual tool-call grammar. Uploads execute through the same spine and preserve failure evidence with addresses.

## Execution and persistence

The **calculation** button executes the actual spine's expression IR. Upload JSON with a `realizer` to use `expression-ir`, `predicate-search`, registered `capability`, `state-machine`, or `dependency-graph`. A machine spec supplies `definition` and `events`; a graph supplies `nodes` with the existing spine's `realization` and dependency fields.

IndexedDB retains the journal on supporting browsers. If access throws, the adapter tries localStorage and reports its actual mode. Memory sessions require export to retain history. Replay restores mesh learning, field commits, Klein state, ATO episodes and lineage by replaying journal inputs. Replaying executable uploads repeats execution; exports contain original file bytes and should be treated as the user's private project history.

`Foundation.registerPiece()` records full addresses, source, parents, inherited qualities, form and exact positive rational proportion. Descendants inherit a subset of their parents' qualities. `Foundation.fitPieces()` evaluates supplied predicates at a specified depth and records the supplied fit or mismatch consequence. It shares the result with the live mesh. Physical connection rules are supplied as contracts; no physical law is fabricated by this adapter.

These legacy implementations require further source-grounded integration before the complete dimensional system can be declared verified.

Foreign-artifact execution uses the supplied bridge's available local paths and recorded synthesis attempts. This does not establish execution of every possible language, package, hardware effect or arbitrary program. Worker-free raw JavaScript uses the supplied iframe chamber; a same-thread infinite loop cannot be preempted by its timer.
