# Semantic SpaceTime Swarm — review handoff, 29 October 2026

## Read this first

This is a research checkpoint, not a completed agentic reality. It preserves the
original Generative Address System and the earlier browser prototype. The newer
CPU runtime lives in `observable-swarm/native/`; the older browser code is legacy.
No deployment, merge into main, or integration into the original address engine
is part of this checkpoint.

## Intended architecture (user requirements)

The swarm itself must carry computation through constituent relationships.
General identity/addressing, interaction, execution, feedback and persistence
mechanisms are permitted; task-specific finished functions must not be disguised
as emergent formations. Linux-native JavaScript, offline CPU execution, no GPU,
Web Worker, remote model, HTTP API or separate backend required for the substrate.
An installed observation interface must inspect the same running state.

Five dimensions are present at every scale, with variable nested layers:
Movement, Evolution, Being, Design, Space. Four fields contribute and Space is a
resulting condition. Personality/Design expressions remain distinct requirements.
Current explicit sequence mapping: Movement=King Wen, Evolution=Mawangdui,
Being=Fu Xi. Design/Space sequence mapping remains unresolved. A dimension's
expressions include the others; do not implement five isolated sequential stages.
Leading dimension must be observed through an event, not predetermined by stack.
Six potential expressions and the two action-capable possibilities remain
unresolved rather than arbitrarily selected.

Micro-level writing/encoded relationships must constitute meso forms and macro
images/scenes. Neural connections carry function; material meshes carry form,
with distinct measurable consequences of disruption. All are constituent
organizations, not independent image overlays. The user wants ingestion,
reconstruction, composition, learned walking and eventual new apps/tools/worlds.
These are goals, not established capabilities. Capital-letter direction rules,
Bhan Tugh correspondences, angular reach, three-layer connected passage through
Being, and context/day-supported relationships need formal source-grounded rules.

## What currently executes

- Persistent constituent IDs, directed signal relations, journal/event history,
  deterministic replay and disk persistence with provenance comparison.
- Local movement, encounter opportunities, feedback-driven connection growth,
  weakening/reorganization, and formation membership tracking.
- Sparse CPU gather/weighted propagation/grouped accumulation with scan offsets.
- Learned affine transformations on held-out inputs; connection-level traces,
  disruption and restoration controls.
- A learned linear delayed recurrence with self-observation; not a newly emerged
  hidden neural architecture.
- Small 4x4 image reconstruction through learned scalar relations and a second
  learned operation on reconstructed values. Pixel positions and input/output
  contacts are supplied; this is not emergent object geometry.
- Persistent environmental visit traces enabling later contact opportunities;
  externally arranged visits and supplied policy, not autonomous navigation.
- Feedback-guided repair of reversible relation disabling; the diagnostic search
  itself is programmed, not learned.
- Context-weighted mutation proposals and elastic geometric settling using
  learned weights; experimental numerical rules, not biological/dimensional laws.
- CLI observation of the same local state. Static SVG evidence is available.

Five-dimensional context records are experimental bindings. Their presence is
not evidence that the user's dimensional semantics have been implemented.

## What has NOT been demonstrated

Source-derived five-dimensional dynamics; autonomous learning of the full
primitive language; emergent hidden neural architectures; a distinct material
mesh with boundary/rupture mechanics; high-quality dog/people reconstruction;
learned walking; photorealistic scenes; autonomous arbitrary-program synthesis;
teleportation rules; a live installed graphical window; backend-free integration
of all donor tools; proof of general computational sufficiency.

Current `relax` is an elastic graph rule, not a material mesh. Existing routines
named repair, mutation and traces use supplied experimental policies. Original
browser rendering and worker code remain historical, not the required foundation.
Dockerfile is optional packaging and has not been verified in this environment.

## Existing address system: targeted source review

Original directory:
`Synthia-Generative-Address-Morphology-Integrated-v0.2.1-RUNNABLE/`.
Reviewed its README and execution-spine canonical-address / execution-address-
resolver modules. The address schema preserves 13 fields and five named
dimensions. The resolver's fallback projects artifact/execution evidence through
salted hashes and explicitly disclaims intrinsic semantic meaning. The Morph chat
wrapper instead requires supplied active addresses. These are different paths;
neither should silently replace the user's relational/dimensional address rules.
Its README describes an HTTP core and model-facing chat paths: these are not the
backend-free native substrate developed here. Published upstream test claims
were read, not independently rerun as part of this checkpoint.

## Sources and existing pieces reviewed

See `native/PRIMARY-CONDITIONS.md` and `docs/supplied-packages-review.md`.
Klein's supplied papers were read, including key visual/Boolean/tree/hierarchy
figures. A supplied Kimi package's ATO module reproduced the paper's iconographic

conflict with current user corrections and must not be imported unchanged.

## Reproduce / review

From `observable-swarm`, with Node >=22:

```
npm test
npm start
npm run experiment
npm run experiment:encounters
npm run experiment:adaptation
npm run experiment:memory
node native/primitive-experiment.mjs
```

Focused later checks:
`node --test tests/repair.test.mjs tests/traces.test.mjs tests/bridge.test.mjs`.
Evidence reports and SVGs are under `evidence/`. Raw snapshots are compressed in
`evidence/snapshot-parts/` in the published checkpoint. Run
`python3 scripts/restore-evidence.py` to verify, join and extract the archive
into the original evidence paths. Tests do not depend on the archive.
CPU/memory reports include runtime and histories; they are not isolated benchmarks.
Restricted child spawning is reported by native-io checks; installed-app UI and
Docker execution have not been verified. Prior plans/docs remain historical;
this handoff and PRIMARY-CONDITIONS describe current scope and limits.
