# Primary conditions: executable research baseline

Approved direction: the user's corrected proposal in the conversation, including native image reconstruction and backend-free operation. The older REVISED-PLAN-FOR-APPROVAL.md does not override those corrections.

## What this increment establishes

The native entry point is `node native/main.mjs`. It executes the substrate directly, including when the terminal inspector is active. There is no service, HTTP listener, browser, GPU, Web Worker, model dependency, or external inference call. The JavaScript runtime supplies CPU execution and file access. Container packaging is optional; the same runtime runs in a Linux VM.

The current graph is an explicitly limited adaptive linear computational formation. It is not a universal computer, a biologically realistic neural network, or the completed five-dimensional theory. No grammar, image reconstruction, reasoning, or application-generation handler is in its execution path.

## Dimensional participation in this baseline

Movement supplies ongoing clock/phase and position changes. Evolution retains experience and drives connection adaptation. Being holds realized scalar states and geometric extents. Design supplies relation types, acceptance constraints, and executable composition order. Space exposes the resulting adjacency and formation organization. These occur together for the same constituents; they are not separate networks.

These bindings make the experiment explicit, but do not establish the complete qualitative dimensional morphology. In particular, presence in an inspector is not proof of the full five-dimensional participation demanded by the final architecture. Movement currently constrains spatial contact but does not determine which signal offers are made: experimental fixtures supply those opportunities. This separation is a known gap before autonomous discovery can be claimed.

## Execution versus task knowledge

`substrate.mjs` does not contain either experimental target rule. `experiments.mjs` is the environment: it generates training examples, provides desired measurements as feedback, and scores held-out execution. During execution, only input contacts enter `evaluate`; expected answers are not available there.

Relations start absent in the learning experiments. Accepted opportunities are an explicit scaffold; they do not specify the correct weights or routes. Experience creates and adjusts connections. The first task learns an affine transformation and is compared with nearest-example memorization. The image task learns routing across a fully offered sensor/surface contact set using random patterns, then reconstructs a previously unseen asymmetric glyph.

These tasks demonstrate a limited class of supervised learned operations. Choosing an input/output encoding is a scaffold and must remain visible. This baseline does not prove that the swarm independently invents its own tasks, sensors, arbitrary nonlinear algorithms, or operators.

## Image information, realized form, and reuse

The fixture supplies 16 measured grayscale samples and their spatial coordinates. Each sample becomes a persistent input constituent. Separate persistent surface constituents realize output samples through learned relations. This separates measured source information from reconstructed output. The display adapter reads surface values and coordinates only; it cannot access the source array.

The learned surface contacts subsequently feed a second learned numerical formation in the same graph. No new decoder or separate task runtime reinterprets them. Pixel ablation, recovery, restart, and reuse are measured in the report.

This is not emergent object geometry: the 4×4 sample layout is supplied, and grayscale values are measurements. Shape/color semantics, naturally formed boundaries, cross-modal rules, and the Being realization law are unresolved. Fixed constituent extents demonstrate that geometry can affect motion, separately from the learned pixel experiment; the latter must not be represented as having learned those boundaries.

## Persistence and inspection

Snapshots contain nodes, edges, opportunities, formation identity, events, learned parameters, current trace, and the complete operation journal. Saves use an atomic rename. Restore rebuilds from the operation journal and rejects state/provenance disagreement. This is deterministic verification, not authentication against a malicious author who changes both.

The terminal directly inspects the live in-process substrate. `trace` exposes individual executed contributions. Each interaction event records its journal position so an earlier execution can be reproduced through `Substrate.replay(journal.slice(0, position + 1), options)`. Full current traces are retained without duplicating every trace in every historical event.

Snapshots and reports are local files. Journal replay and detailed histories currently grow without bound and need checkpointing and storage budgeting before long-running use. Restore is linear in recorded operations and can be expensive; no real-time or production-scale performance claim is made.

## Encounter-discovery increment

The `discovered-dag` policy removes supplied ranks from execution ordering. Order is computed from active connections. An explicit acyclicity constraint remains; this is not recurrent neural dynamics. Existing baseline experiments retain their original ranked policy for comparison.

With an encounter policy enabled, movement generates local contact observations. Repeated contacts meeting a configured radius/count condition offer directed signal opportunities, subject to contact types and acyclic execution. Opportunities begin absent. Feedback correlation develops actual edges from those opportunities. Encounters are cumulative historical counts, not necessarily consecutive. Established edges can persist after separation, supporting retained learned paths.

The environment supplies input/output contacts, initial positions, motion phases, an encounter radius/count, scalar propagation and credit rules, and example feedback. It does not supply the successful wiring pattern or execution ranks. These are general experimental conditions; the geometry is not claimed to be source-derived semantic distance. No ACO/PSO reproduction, five-dimensional directional law, or biological neural topology is implied.

`encounter-experiment.mjs` tests held-out execution, relevant-edge disruption, restoration, exact replay and filesystem restart. Controls disable encounters, move the target out of reach, or require more encounters than the run supplies. The same numerical examples cannot create connections in those controls. A distant input also remains unconnected despite being present in every example.

This advances the connection-opportunity gate described above. Further gates remain: developing hidden functional organization, nonlinear/recurrent learning, autonomous structural revision beyond this offer/credit rule, and computational meshes with a specific causal and structural criterion. All-five-dimensional interpretations remain the explicitly limited experimental bindings already listed, not completed qualitative morphology.

## Adaptation increment

An optional experimental adaptation policy counts feedback updates whose absolute learned contribution weight remains below a configured threshold. After a configured patience interval, that relation is retired. Its identity, weights, update history and retirement cause remain in the persistent state. This is a general numerical pruning mechanism, not a source-derived decoherence law or proof that small weights are always dispensable. Usage/disuse decay remains a separate mechanism and requires further experiments.

Previously encountered opportunities remain in memory. Birth or rebirth of an encounter-derived relation under this policy requires a sufficiently recent contact as well as feedback correlation. Thus obsolete remote opportunities cannot immediately recreate pruned connections from noise alone. Existing working relations are not deleted merely because constituents separate.

The external environment can change a constituent's position through the journaled `place` primitive. This changes encounter conditions without naming any new edge or prescribing a new computation. Its before/after state and cause remain inspectable. The adaptation fixture changes both an input's accessibility and the example relationship; these are experimental interventions, not actions generated autonomously by the swarm.

The fixture first learns a relationship involving `a` and `b`. It then makes `a` remote, allows encounters with `c`, and supplies examples whose outcomes depend on `b` and `c`. The old relation's coefficient weakens under feedback and is retired; a newly encountered relation acquires its contribution. Held-out inputs test the new function. Controls withhold either subsequent feedback or the new contact, and must fail to acquire the new function. Saved state and exact replay retain both the working configuration and the retired relation's causal history.

The demonstrated reorganization is still a limited adaptive linear DAG. It is not evidence of automatically developed hidden neural layers, a computational mesh, source-derived sensory realization, or the full five-dimensional morphology. No new task-specific operation has been installed in substrate execution.

## Temporal memory and structural inspection increment

An opt-in `temporal` execution policy reads every connection's source value from the preceding propagation interaction. It commits newly computed scalar states synchronously. Delayed connections allow recurrent cycles without introducing an instantaneous cyclic equation. An idle movement interval does not perform propagation; traces retain the actual source-state tick rather than pretending that state was updated during idle motion.

Optional self-observation permits a constituent's retained prior state to become a candidate input to itself after repeated local observations. This is an explicitly supplied general memory primitive, distinct from an encounter with another constituent. Opportunity provenance identifies `local-self-observation` separately from `local-encounter`. Feedback determines whether a self-connection develops and its learned weight; no recurrent weight or temporal target rule is embedded in substrate execution. Current credit assignment is a local one-step residual approximation, not backpropagation through time or a general recurrent learning solution.

The external memory experiment provides example sequences of a stable linear recurrence. Held-out execution receives only current inputs, not target values, and tests the learned temporal response. A control removes self-observation opportunities; additional interventions disable/restore the recurrent connection, compare identical current inputs after different histories, and restore saved state. The observer reads current source values, not the event journal, to execute delayed propagation; historical logs support audit/replay but do not calculate the answer.

`inspection.mjs` computes directed strongly connected components from active relations, identifies self-connections, and reports the actual scalar update policy. It is read-only. A structural label such as recurrent linear signal network describes observed wiring and execution semantics; it does not assert spiking neurons, emergent hidden-layer architecture, useful memory, or a computational mesh. Those behavioral claims need separate causal experiments. Formations' five contexts remain the same experimental bindings; no new dimensional law is inferred from recurrence.

Remaining work includes variable delays/context length, asynchronous local clocks, useful self-developed internal units, recurrence stabilization under broader conditions, configuration-sensitive disuse, I Ching/Klein-derived transitions, source-derived dimensional addressing, and functional mesh criteria. The optional temporal policy does not automatically replace or reinterpret existing acyclic saved states.

## CPU primitives: implementation and evidence

References: [Meister, Yoshimura and Kao, 2023](https://gpuopen.com/download/GPU_Programming_Primitives_for_Computer_Graphics.pdf),
[Chatterjee, Blelloch and Zagha, 1990](https://www.cs.cmu.edu/~guyb/papers/sc90.pdf).
These sources motivate general execution mechanisms, not dimensional laws or
semantic capabilities. Their GPU/vector-machine performance results do not
establish performance on this CPU implementation.

`primitives.mjs` implements exclusive count offsets (including empty groups),
stable scatter of active directed relations into destination segments, lazy
source gathering, multiplication by learned weights, and seeded segmented
accumulation. `Substrate.evaluate` actually uses this path. It rebuilds the
layout each evaluation so formation changes cannot leave stale connections.
Temporary dense indices never replace persistent constituent or relation IDs.
Relations retain their independent histories; the layout holds references to
those same objects. Reduction order remains bias-first and insertion-stable,
preserving exact replay of existing journals.

Existing topology-derived DAG scheduling and reverse residual transport remain
in use. Delayed networks gather previous state through the same kernel. This
is logical distribution across connections on a sequential CPU, not a claim of
parallel threads. Custom hashing (Map already provides lookup), radix sorting,
parallel queues and recursive hierarchy scans are deferred: current formations
are not membership trees, and inventing one would not prove recursive emergence.
Bottom-up/top-down membership propagation needs explicit nesting, shared-child
and cycle semantics before activation. Reverse residual transport is credit
propagation, not evidence that those hierarchy semantics exist.

Run `node native/primitive-experiment.mjs`. The external fixture supplies examples
of an affine transformation; the runtime receives inputs and scalar feedback,
not coefficients or a task dispatcher. Initially absent relations develop from
local encounters and feedback. Held-out values extend beyond the training range.
The experiment records connection-level contributions, learned weights,
relevant-connection disruption/restoration, provenance replay and actual disk
save/load. The same numerical family is supplied by the universal scalar
primitive; this proves acquired coefficients/connectivity, not invention of a
new computational primitive or unrestricted generalization. Neural architecture,
meshes, full five-dimensional realization and image geometry emergence remain
separate acceptance requirements.

The report includes logical operation counts, wall time, process CPU time,
RSS, heap use and process peak RSS. Measurements include histories, training,
assessment and replay; they are not an isolated kernel benchmark. Counters are
regenerated by journal replay rather than becoming constituent identity. Resource
limits and performance of large formations remain uncharacterized.

## Feedback-driven structural recovery experiment

`reorganization.mjs` supplies an experimental universal bounded perturbation
policy, not an emergent diagnostic ability or source-derived dimensional law.
It tests single directed-connection enable/disable changes on provenance-replayed
copies, receives a scalar environmental cost, and commits only improving changes
through the substrate's journalled disruption interface. Fault IDs and target
coefficients are absent from the policy. Rejected trials and accepted decisions
are retained in the experiment report; accepted changes persist in the substrate
journal. The search reads available relations, including their enabled flags;
it does not receive privileged access to which flag changed in the fault event.

`repair-experiment.mjs` trains the existing encounter-developed affine formation,
externally disables one connection, supplies 24 performance-feedback examples,
and assesses recovery on 60 separate inputs. Tests repeat with either learned
connection disrupted. A constant-cost control must abstain from changes. This
establishes feedback-guided recovery of reversible disabling, not discovery of
diagnosis, replacement of destroyed relations, arbitrary fault handling or
medical equivalence. Weights remain learned and unchanged during structural
repair. CPU/memory costs include replayed trial copies, which will not scale
well to large formations. Five-dimensional qualitative repair rules remain
unresolved rather than being inferred from the illness analogy.

Evidence: `evidence/repair/report.json` and `state.json`; actual disk restoration
is checked in addition to in-memory provenance replay. Reproduce the behavioral
checks with `node --test tests/repair.test.mjs`.

## Context-dependent variation and relational form bridge

`variation.mjs` supplies a bounded stochastic proposal policy: recent weight
instability increases sampling weight; accumulated usage reduces it; a nonzero
floor preserves exploration. Uniform sampling is available as a control. Usage
is a proxy, not demonstrated essentiality. Biological inspiration is mutation
bias associated with genomic context (Monroe et al., 2022,
https://doi.org/10.1038/s41586-021-04269-6), not evidence for this numerical formula.
No mutation is automatically beneficial or targeted to a desired future outcome.

`Substrate.vary` journals before/after weights and causes. `Substrate.relax`
implements an explicitly experimental elastic constraint: an enabled relation's
rest length is 0.1 plus the magnitude of its learned signal weight. Simultaneous
position corrections move nonfixed constituents. This is a declared new
computational convention, not a derivation of source dimensional morphology.
It uses the same constituent positions that affect ordinary encounters and
movement, rather than a separate decorative layout. There is no collision
projection in relaxation itself, so arbitrary formations may overlap or fail
to converge. No general convergence guarantee is claimed.

`bridge-experiment.mjs` replays the encounter experiment with fixed input
anchors and a movable internal constituent. It then settles the formation,
samples a context-weighted weight variation, and measures geometry and output
changes, subsequent settling and restart. SVG output draws only those same
constituents and active relations; no independent image/model is substituted.
The observer adapter omits causal events but is not a security boundary. Developer
reports and persistent state retain full causes. Numerical settle steps are
not physical clock time, and the demonstration does not establish a mesh,
recognizable scene, semantic understanding or an emerged mutation policy.

This integrates learned sparse execution, provenance and experimental geometry;
trace-mediated contacts, delayed memory and repair retain their separate tested
experiments. They are not all active in this fixture. Hexagram transition counts,
IDEA operators and source-specific dimensional mappings remain unactivated until
verified rules connect them to constituent transitions. Nothing here assigns
which two of the six potentials act or identifies event leadership prematurely.

Artifacts: `evidence/relational-bridge/{report.json,state.json,before.svg,after.svg}`.
Checks: `node --test tests/bridge.test.mjs`. Results apply to this seeded fixture;
multiple seeds and topology/geometry controls are needed before claiming a
benefit for context-weighted mutation over uniform mutation.
